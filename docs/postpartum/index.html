はちみつは1歳まで絶対に与えない

1歳未満の赤ちゃんは腸内環境が整っておらず、はちみつに含まれるボツリヌス菌の芽胞が腸の中で増えて毒素を作り、乳児ボツリヌス症を起こすことがあります。国内で死亡例も報告されています。加熱しても芽胞は死にません。はちみつ入りの飲料、お菓子、パン、離乳食レシピにも注意を。1歳を過ぎれば与えて大丈夫です。

離乳食を始める時期を遅らせても食物アレルギーの予防にはならない、というのが現在の考え方です。初めての食材は、体調のよい平日の午前中に、少量から。何かあったときに小児科が開いている時間帯を選ぶのがポイントです。

パートナーができること

作る係より、食べさせて片づける係を引き受けるほうが実際には助かります。離乳食は作るのに30分、食べさせて片づけるのに40分かかるので。まとめて作って小分け冷凍する日を、週末に自分の担当として固定するのもおすすめです。

赤ちゃんの安全

事故と突然死を防ぐ

1歳になるまで、寝かせ方で気をつける3つ

  1. あおむけに寝かせる — 医学的な理由でうつぶせを勧められている場合を除き、寝かせるときは必ずあおむけに。乳幼児突然死症候群（SIDS）の発症率が下がります
  2. できるだけ母乳で育てる — 母乳で育てられている赤ちゃんのほうが、SIDSの発症率が低いことがわかっています
  3. たばこをやめる — 妊娠中の喫煙も、周囲の人の喫煙も、SIDSの大きな危険因子です

そのほか、この1年で気をつけること

  1. 絶対に揺さぶらない — 泣きやまないときに激しく揺さぶると、脳に重い障害が残ることがあります。どうしても無理なときは、安全な場所にあおむけで寝かせて、数分その場を離れていい、と2人で決めておく
  2. 顔まわりに何も置かない — やわらかい布団、枕、ぬいぐるみ、タオルは赤ちゃんの顔の近くに置かない
  3. ソファや大人用ベッドに寝かせたまま離れない — 寝返りが始まる5か月ごろから転落事故が増えます
  4. 誤飲に注意 — トイレットペーパーの芯を通るものは口に入ります。ボタン電池、たばこ、薬、小さいおもちゃは手の届かない場所へ
  5. やけどと入浴 — 湯船に浮かぶ浮き輪や補助具も含め、お風呂で目を離さない。数センチの水でも溺れます

  • 母乳・ミルクを受けつけない／おしっこが半日以上出ない
  • ぐったりして目を合わせない、呼んでも反応が鈍い
  • 唇や顔色が青白い、紫っぽい
  • 頭を強く打った — 嘔吐や機嫌の悪さが続くとき

ママの心のサイン

  • 眠れない、眠る時間があっても眠れない
  • 食べられない、味がしない
  • 涙が止まらない状態が2週間以上続く
  • 赤ちゃんをかわいいと思えない、自分を責め続ける
  • 消えてしまいたい、と思うことがある

産後数日から2週間ごろに気分が不安定になるのは「マタニティブルーズ」で、多くは自然におさまります。でも2週間を超えて続くときは産後うつの可能性があります。産後2週間・1か月の産婦健診はそれを見つけるための健診でもあるので、つらさは正直に話してください。健診を待てないときは、産院か市区町村のこども家庭センターへ。産後ケア事業（宿泊・日帰り・訪問）も使えます。

パートナーができること

産後うつは本人が自覚しにくく、「がんばりが足りない」と自分を責める形で出ることがあります。気づけるのはいちばん近くにいる人です。上のサインが2週間続いていたら、「疲れてるだけだよ」と流さず、産院か自治体の窓口に一緒に連絡してください。予約を取る、同行する、その間赤ちゃんを見る。そこまでやって初めて相談にたどり着きます。産後うつは治療できるもので、本人の性格の問題ではありません。
