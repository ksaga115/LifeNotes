くらしのノート

困ったときに、ここを開く

人生で何度かしか通らないのに、そのたびに期限と手続きに追われることがあります。 調べようとすると、広告と関連記事とランキングに埋もれて、肝心のことが読めません。

知りたいのはたいてい2つだけです。いま何をすればいいのか。いつまでなのか。 それだけを、スマホの1画面で追えるようにしたノートを置いています。

おくやみノート身近な人が亡くなったあとの手続きを、期限の順に。死亡届の7日から、相続登記の3年まで。介護のノート親の介護が始まったら。まず地域包括支援センターへ。認定、ケアプラン、費用、仕事との両立まで。退職のノート退職日から。健康保険、年金、失業給付、住民税、確定申告。準備中確定申告ノート還付申告、副業の申告、事業所得。何を集めて、いつまでに出すか。期限は自動で数えます。防災の備蓄ノート家族構成から必要量を出して、期限を追う。準備中引っ越しノート転出・転入の14日から、ライフライン、免許証まで。準備中

このノート群の決めごと

制度や基準は、必ず一次情報で裏を取る
金額、期限、手数料、対象になる人。所管の官庁・機関で確認したうえで書き、 その項目に出典リンクを置いています。記憶で書くと、制度の情報は必ず古くなるからです。
裏の取れた数字と、段取りの提案を分ける
出典を付けられる制度・基準と、付けられない一般的な目安や進め方のコツを、 ページの中ではっきり区別しています。読む人が、信じる範囲を自分で決められるようにするためです。
自治体や加入先で変わるものは、断定しない
窓口の名前、金額、持ちものは地域や保険者で変わります。 そこは数字を書かず、「どこに聞けばいいか」だけを書いています。
入力したものは、その端末から出ない
日付もチェックの状態も、ブラウザの中（localStorage）にだけ保存されます。 サーバーには送られず、他の人にも見えません。アクセス解析も広告も入れていません。
ホーム画面に置いておく iPhone なら Safari で開いて 共有 → ホーム画面に追加、 Android なら メニュー → ホーム画面に追加。 アプリのように全画面で開けます。アカウント登録もインストールも要りません。
個人が作っているページです。広告もアクセス解析も入っていません。
内容の正確性には努めていますが、最終的な判断は各窓口・専門家の案内を優先してください。
